# Large-context extension

This subdirectory contains the pathway/context extension used in the manuscript's extended-dataset analyses. It is provided as a trimmed public synchronization of the manuscript-facing pathway/context branch, with lightweight processed inputs and compact example summaries.

## What is included

- `data/processed/`: disease-level auxiliary feature tables and alignment metadata used by the manuscript pathway/context analyses.
- `data/processed_pathway_only/`: lightweight pathway-only processed dataset used by the matched prior-setting experiments.
- `dataset_utils.py`: lightweight helper functions for name normalization and mapping-table loading.
- `train_sphlcMga_core_vs_pathway.py`: core training entry for SPHLCMGA, pathway-only, context-only, and joint context-pathway settings.
- `run_sphlcMga_pathway_context_study.py`: matched comparison across base, pathway-only, context-only, and joint settings.
- `analyze_differential_gain.py`: differential hard-case correction analysis.
- `analyze_prior_noise_robustness.py`: prior-noise robustness summary.
- `run_sphlcMga_prior_noise_robustness.py`: scenario runner for pathway/context prior corruption.
- `run_pathway_context_ko_consistency.py`: ncRNA/pathway/context knockout consistency analysis for the representative case.
- `trace_pathway_context_evidence.py`: pathway/context motif tracing for the representative response-switching case.
- `analysis_examples/`: compact manuscript-aligned summary tables and figures.

## Scope of the public upload

This public upload is aligned to the pathway/context experiments reported in the manuscript. Files that were only needed for broader exploratory graph construction, including explicit protein-level bridge resources and intermediate construction packages, are intentionally omitted.

The bundled `analysis_examples/` directory is summary-oriented. It is meant to document the manuscript-facing outputs without shipping full fold-by-fold training directories, saved fold checkpoints, or large intermediate prediction files.

## External dependencies

Some scripts depend on resources generated by the main repository workflows, especially:

- `../datasets/metadata/`
- `../model.py`
- `../external_validation/prepared_outputs_example/dataset2_all_external_positive.csv`

Runtime outputs produced in new runs are ignored by the repository-level `.gitignore`.

## Example commands

Matched pathway/context study from scratch:

```bash
python large_context/run_sphlcMga_pathway_context_study.py
```

Differential correction analysis after generating local matched-study outputs:

```bash
python large_context/analyze_differential_gain.py \
  --standard-dir large_context/outputs_sphlcMga_pathway_context_study/base \
  --rich-dir large_context/outputs_sphlcMga_pathway_context_study/context_pathway_all \
  --output-dir large_context/outputs_sphlcMga_pathway_context_study/differential_gain
```

Representative evidence trace after generating local matched-study and differential outputs:

```bash
python large_context/run_sphlcMga_pathway_context_study.py --output-root large_context/outputs_sphlcMga_pathway_context_study
python large_context/analyze_differential_gain.py \
  --standard-dir large_context/outputs_sphlcMga_pathway_context_study/base \
  --rich-dir large_context/outputs_sphlcMga_pathway_context_study/context_pathway_all \
  --output-dir large_context/outputs_sphlcMga_pathway_context_study/differential_gain
python large_context/trace_pathway_context_evidence.py \
  --rich-dir large_context/outputs_sphlcMga_pathway_context_study/context_pathway_all \
  --differential-file large_context/outputs_sphlcMga_pathway_context_study/differential_gain/aligned_oof_predictions.csv \
  --output-dir large_context/outputs_sphlcMga_pathway_context_study/evidence_trace
```

Representative pathway/context knockout consistency analysis after generating the local evidence trace:

```bash
python large_context/run_pathway_context_ko_consistency.py \
  --checkpoint-root large_context/outputs_sphlcMga_pathway_context_study/context_pathway_all \
  --case-file large_context/outputs_sphlcMga_pathway_context_study/evidence_trace/evidence_trace_case.csv \
  --output-dir large_context/outputs_sphlcMga_pathway_context_study/ko_consistency
```

Prior-noise robustness from scratch:

```bash
python large_context/run_sphlcMga_prior_noise_robustness.py
```
